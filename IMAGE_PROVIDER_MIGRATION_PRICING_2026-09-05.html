Что это значит для миграции

13 моделей из 23 полностью готовы к схеме «APIMart основной / CometAPI резервный» уже сегодня. Из оставшихся 10: 3 модели (Flux Kontext Pro/Max, Nano Banana v1) закрываются точечным резервом на laozhang.ai — модель реально есть в его каталоге, просто маршрут отличается от CometAPI. 5 моделей (Qwen Image 2.0, Qwen Image 3.0, Qwen Image 3.0 Pro, Wan 2.7 Image, Z-Image Turbo) — по-прежнему без резерва вообще: их нет ни у CometAPI, ни у laozhang.ai, они и были добавлены в каталог именно потому, что раньше существовали только у apimart. 1 модель (GPT Image 1 Mini) доступна только через CometAPI — если он «резервный», для этого slug он фактически становится единственным. И 1 модель (DALL-E 3) не продаётся ни у APIMart, ни у CometAPI — только на laozhang.ai, который убирается.

По ценам: после этого пересчёта все 22 модели с хотя бы одним конкурентом сидят в коридоре −4.8%…+2.7% от рынка (посчитано по новой цене). Единственный плюс в таблице — GPT Image 1 (+2.7%) — и это осознанный результат пола по марже, а не недосмотр. GPT Image 1.5 и DALL-E 3 остаются без ориентира — конкурентов не продают, а у DALL-E 3 к тому же нет опта ни у APIMart, ни у CometAPI для расчёта пола. GPT Image 1 Mini — единственная модель, где пол формально требует роста цены, но не применён из-за недостоверного опта (см. примечание в таблице).

Методология. «Опт» переведён в рубли по курсу 80 ₽/$ (тот же курс, что TOKEN_OVERAGE_USD_RUB и TARIFFS.md для оценки себестоимости). Токенные модели (GPT Image 1/1.5/2, Nano Banana 2/Pro) переведены в ₽/фото через число токенов на изображение, уже согласованное и зафиксированное в align_image_pricing_to_competitors.py и PROVIDER_PRICE_COMPARISON_2026-09-03.md: gpt-image-2 = 1767 ток/фото, gpt-image-1 = 1050 ток/фото (оба — реальная medium-цена OpenAI, не плоское допущение), gemini-3-pro-image/gemini-3-1-flash-image = 1290 ток/фото (официальное значение Google). gpt-image-1-5 использует 1050 ток/фото по аналогии с gpt-image-1 (не подтверждено отдельно), gpt-image-1-mini — грубое допущение 1120 ток/фото (открыто помечено неподтверждённым в обоих исходных документах). Часть моделей APIMart и CometAPI сами уже дают готовую цену за фото (не за токен) — для них конверсия не нужна, взяты цифры напрямую с их тарифных таблиц.

«Наша цена» — актуальные значения после коммита c558e6f (align_image_pricing_to_competitors, применён 2026-09-05/06) для 13 моделей, участвовавших в раунде выравнивания; для остальных — либо нетронутые тем же раундом (нет конкурента ни у одного источника), либо исходный посев add_laozhang_models.py для трёх моделей вне раунда (gemini-2-5-flash-image, seedream-4-0, qwen-image-2-0 — помечены в таблице). Докер недоступен локально в момент подготовки этого документа — ни одно из значений не сверялось напрямую с живой БД.

RouterAI и Gen-API показаны отдельными столбцами — RouterAI (живой снимок каталога routerai.ru, фильтр «Изображения», 49 моделей/4 страницы, снят 2026-09-05) и Gen-API (собственный прайс-лист, файл genapi.txt, снят 2026-09-03). «—» значит конкурент эту модель не продаёт. Там, где страница модели RouterAI показывает цену «₽/1M токенов» — это НЕ цена за фото напрямую (см. предупреждение пользователя по скриншоту страницы GPT Image 2 на routerai.ru): использованы уже пересчитанные по реальным токенам-на-фото значения из предыдущего раунда сверки, а не сырые цифры с карточки.

«vs рынка» — отклонение нашей цены от меньшего из двух конкурентов, (наша − мин) / мин × 100%. Зелёный бейдж — мы дешевле в коридоре −3…−7% (соответствует целевой формуле «конкурент × 0.95» из сентябрьского выравнивания); жёлтый — мы дешевле, но заметно сильнее цели (аномалия, не входила в раунд выравнивания); красный — мы дороже рынка. «нет данных» — обе площадки не продают модель.

Резерв laozhang.ai для 3 моделей (Flux Kontext Pro/Max, Nano Banana v1/gemini-2.5-flash-image) назначен на основании прямой проверки по all_models_laozhang.ai.txt (актуальный список моделей нашего аккаунта laozhang) — модель в списке есть, значит канал технически рабочий; сам опт по laozhang в это расследование не входил (в столбце «Резерв (опт)» стоит «laozhang» без цифры). Для 5 моделей без резерва (Qwen Image 2.0/3.0/3.0 Pro, Wan 2.7 Image, Z-Image Turbo) той же проверкой подтверждено, что их нет в списке laozhang вообще — это и стало причиной их изначального добавления через apimart в коде (add_laozhang_models.py, комментарий у блока «Новые модели apimart с task-полл контрактом»).
