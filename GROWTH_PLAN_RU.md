# План привлечения трафика и конверсий — aineron.ru (помимо Яндекс.Директа)

Дата составления: 2026-08-01. Контекст: платная кампания в Яндекс.Директе только
что запущена на небольшом бюджете (см. `YANDEX_DIRECT_PLAN.md`). Этот документ —
что делать **сверх** контекстной рекламы, чтобы расти к цели «№1 в России в нише
доступа к нейросетям без VPN». План составлен с проверкой реального кода
репозитория (не только по описанию из памяти) и живым SERP-ресёрчем на 2026 год.

---

## 0. Главный стратегический вывод

Проверка выдачи по денежным запросам ниши («chatgpt без VPN оплата рублями»,
«агрегаторы нейросетей») показала: топ занимают `habr.com`, `vc.ru`, `sostav.ru`,
`dtf.ru`, `profinvestment.com`, `neurofolder.com` — **ни одного независимого
молодого домена**. Весь трафик в нише сейчас лежит на площадках с чужим
авторитетом. Отсюда два трека, и порядок между ними принципиален:

| Трек | Что | Когда даёт трафик |
|---|---|---|
| **A. Заимствованный авторитет** | Свои статьи на vc.ru/DTF/sostav + попадание в чужие подборки + каталоги | 1–4 недели |
| **B. Свой домен** | 10–15 вручную доведённых страниц под точный long-tail + карточки моделей | 2–5 месяцев |

**Не запускать массовую генерацию 122+ статей через DeepSeek на свежий домен.**
Домен без истории + пачка сгенерированного контента — риск попасть под фильтр
Яндекса на весь сайт. Живой sitemap сейчас: **158 карточек моделей и всего
4 статьи блога**. Правильный шаг — 10–15 статей за 6 недель с ручной доводкой,
не 122 за выходные.

## 1. Шесть фактов из кода, которые меняют план

Проверено в репозитории 2026-08-01 — каждый пункт ломает или спасает канал ниже.

| # | Факт | Последствие |
|---|---|---|
| 1 | **В боте нет обработчика промокодов.** Погашение только веб: `POST /api/v1/billing/promo/` (`src/api/views/billing.py:317`). В `src/telegram_bot/handlers/` совпадений по `promo` нет | Покупатель кода с Plati и подписчик TG-канала **не смогут активировать промокод в боте**. Блокер для каналов §4.1 и §4.2 |
| 2 | **Реферальный бонус начисляется только в `payment_success` Робокассы** (`src/users/views.py:710-738`). Stars, крипта, автопродление — бонуса не дают | Блогер приводит людей в бот → те платят Stars → блогер получает ноль. Гарантированный конфликт при сидинге |
| 3 | **Нативная партнёрка Telegram платит только со Stars-транзакций внутри бота/мини-аппа** (`bots.updateStarRefProgram`) | Партнёрка и своя рефералка монетизируют непересекающиеся платёжные рельсы — нужны обе, и это надо честно объяснять блогеру |
| 4 | **Автобан по IP фактически не работает** на современном фронте: `shadow_banned=True` ставится только в legacy Django-регистрации (`src/users/views.py:176-190`), DRF-путь (`src/api/views/auth.py`) его не ставит | Страх «ShadowBan забанит покупателей с Plati за одним NAT» — почти беспочвен. Реальный риск обратный: защиты от мультиаккаунтов под промокоды сейчас нет |
| 5 | **Нет массовой генерации промокодов** — в management-командах и `PromoCodeAdmin` actions нет | Пул кодов для Digiseller придётся создавать вручную — до 100+ кликов в админке |
| 6 | **UTM нигде не обрабатывается** (нет `utm_` ни в `src/`, ни в `frontend/`). Зато `?ref=` работает: `frontend/middleware.ts:22-37` кладёт cookie `ref_code` на 30 дней | Метрика разберёт UTM сама в отчётах; но связать «платящий пользователь X пришёл из канала Y» в своей БД сейчас нельзя |

Два неиспользуемых актива:
- **Публичные шеринг-страницы уже есть**: `/g/[slug]/` (публичная генерация,
  кнопка «повторить промпт») и `/s/[slug]/` (публичное пространство). Виральная
  петля построена и не эксплуатируется — в sitemap их нет.
- **Бесплатные модели с дневным лимитом работают** (`src/aitext/limits.py`,
  команды `add_groq_free_models`/`add_openrouter_free_models`/
  `add_cloudflare_free_models`/`add_zai_free_models`). Сильный вход в воронку:
  «бесплатные нейросети без VPN и без карты» — запрос массовее, чем
  «купить доступ».

Порядок = приоритет, выполнимо одним человеком за 5–7 дней.

| 2.1 | Своя подборка-сравнение на vc.ru **с личного аккаунта** | 6–8 ч | Высокая | 3–14 дней |
| 2.2 | Активировать нативную партнёрку Telegram | 30 мин | Средняя, растёт | 1–4 недели |
| 2.3 | Заявки в 4 каталога нейросетей | 1–2 ч | Средняя (ссылки + trickle) | 2–6 недель |
| 2.4 | Запуск на Product Radar | 2 ч | Средняя, разовый всплеск | 3–10 дней |

### 2.1. vc.ru — но не так, как все делают

**Критично: публикуйтесь с личного аккаунта, не с аккаунта компании.** По
правилам площадки материалы коммерческих аккаунтов скрываются из ленты и не
индексируются поисковиками; личный блог бесплатно получает SEO-трафик.
Подписка Pro (~49 900 ₽/мес по данным площадки) сейчас не по бюджету и не нужна.

Формат — не «мы запустились», а материал, который уже ранжируется:

> **«Я сравнил 6 российских агрегаторов нейросетей по цене входа и набору
> моделей. Таблица»**

| Сервис | Вход |
|---|---|
| **aineron.ru** | **149 ₽** |
| BotHub | 200 ₽ |
| ChadGPT | 290 ₽ |
| GoGPT | 490 ₽ |
| SYNTX | ~756 ₽/мес |
| GPTunnel | 990 ₽ |

Пишите от первого лица, честно перечисляйте минусы своего сервиса (молодой,
мало отзывов), давайте пользу без регистрации, ссылка на себя — одна, в теле.
Дублируйте (переписав, не копипастой) на **DTF** (раздел «Гайды») и
**sostav.ru/blogs** (самопубликация, по нему уже ранжируется топовая подборка
агрегаторов).

Вторая статья через 5–7 дней: **«Как оплатить ChatGPT из России в 2026:
5 способов, что сколько стоит»** — верхний по частотности запрос ниши (сейчас
держат Хабр/tsnis, vc.ru, РБК Компании). Честный разбор способов (VPN+иностранная
карта, посредники, агрегаторы), ваш сервис — один из вариантов, не единственный.

### 2.2. Нативная партнёрка Telegram — включить сегодня

Флаг `TG_AFFILIATE=1` в коде **ничего не включает** — он только добавляет абзац
текста в `/referral` (`src/telegram_bot/handlers/referral.py:85-97`). Реальное
включение — на стороне Telegram: в настройках бота у владельца появляется пункт
**Affiliate program** (API-метод `bots.updateStarRefProgram`), где задаётся
`commission_permille` (300 = 30%) и `duration_months`.

**Три подводных камня:**
1. Комиссию и срок можно **только повышать**, не понижать — начинайте с
   **25–30%**, не с 50%.
2. Комиссия берётся только со Stars **внутри бота/мини-аппа** — оплаты
   Робокассой на сайте партнёрка не видит.
3. Аффилиаты находят программы сами (Settings → My Stars → Earn Stars) по
   выручке — при нулевом Stars-обороте бот будет внизу списка, канал разгорается
   постепенно, не сразу.

### 2.4. Product Radar

Живая площадка: рекорд 218 заявок в мае 2026, публикуется ~40 из ~160 в месяц,
активный TG-канал, блог на Хабре. Аудитория — фаундеры/продакты/разработчики,
заодно вход в **API-воронку**.

Подавайтесь с углом «проактивный агент в Telegram» (`/task`, `/research`,
`/secretary`, `/mybot`, `/channel`) — это отличает от «ещё одного агрегатора».

### 2.5. Метрика и UTM (без этого остальное — вслепую)

Цели «Регистрация» 80 ₽ и «Оплата» 300 ₽ в Директе уже настроены — теперь нужно
различать источники за его пределами.

Таксономия:
```
utm_source = vc | dtf | sostav | habr | productradar | neurofolder | plati | tg_<канал>
utm_medium = article | catalog | marketplace | tgpost | affiliate
utm_campaign = launch_aug26 | agg_compare | chatgpt_pay
```
Метрика разложит это в «Источники → Метки UTM» сама. Чего не будет без доработки
кода (см. §7) — связи «этот платящий пользователь пришёл из канала X» в своей
БД. Cookie `ref_code` (30 дней) для реферальных ссылок уже работает — для
блогеров используйте `?ref=CODE`, не UTM.

### 2.6–2.7. Первые статьи и Startpack

3–5 статей под long-tail на своём блоге — см. кластеры §3. Startpack (3700+
сервисов, представители могут обновлять карточки) — разово, 1 час, отдача
низкая, но тематическая ссылка + попадание в B2B-подборки. Туда же по
остаточному принципу — `soware.ru`, `toolfox.ru`, `a2is.ru` (актуальность форм
подачи проверять на месте).

**Про «Рубарометр»**: целенаправленно искал — актуального сервиса с таким
названием не нашёл, в план не включаю. Если есть живая ссылка — оценить отдельно.

## 3. Контент-кластеры для SEO

### Своя доменная стратегия (Трек B)

Порядок кластеров = порядок написания. Критерий выбора — низкая конкуренция
доменов + высокая покупательская интенция, не максимальная частотность.

**Кластер 1 — брендо-смежный (пишем первым, ранжируется быстрее всего)**
```
BotHub альтернатива / аналоги
GPTunnel аналог дешевле
ChadGPT vs BotHub vs aineron — сравнение цен
альтернатива GoGPT
```
Аргумент — цифры из TARIFFS.md: вход 149 ₽ против 200/290/490/990 ₽. Сравнение
должно быть честным — где конкурент лучше, так и писать, иначе не переживёт ни
модерацию площадок, ни доверие читателя.

**Кластер 2 — «оплата и доступ» (высокая покупательская интенция)**
```
как оплатить ChatGPT из России 2026
Midjourney оплата российской картой
Claude без VPN в России
Sora из России как получить доступ
подписка на нейросети рублями без иностранной карты
```

**Кластер 3 — «<модель> без VPN» на карточки моделей, 10–15 штук, не все 158**
Отбирать по спросу: GPT-4o, GPT-5.x, Claude Opus/Sonnet, Gemini, Midjourney,
DALL·E/Flux, Sora, Veo, Kling, DeepSeek, Qwen, Grok. Карточки уже сильные —
JSON-LD (SoftwareApplication + BreadcrumbList + FAQPage) подтверждён в коде,
блок `offers` в рублях рендерится при `CURRENCY==="rub"` (на .ru есть).
**Действие:** прогнать 3–4 карточки через валидатор структурированных данных
Яндекс.Вебмастера — убедиться, что разметка доезжает до HTML, а не теряется в
клиентском рендере.

**Кластер 4 — «бесплатно» (самый массовый вход в воронку, недоиспользован)**
```
бесплатные нейросети без VPN и регистрации
бесплатный ChatGPT на русском без VPN
какие нейросети работают в России бесплатно
```
Реально есть бесплатные модели с дневным лимитом + грант 10 ₽ новому
пользователю. Конкуренты на этом запросе продают платную подписку — можно дать
буквально то, что человек искал. Лучший канал наверх воронки, уже оплачен
разработкой.

**Кластер 5 — разработчики (другая воронка, другой LTV)**
```
OpenAI-совместимый API из России
API нейросетей с оплатой в рублях
подключить GPT к Cursor / Continue без VPN
```
Меньше объём, выше чек, почти нулевая конкуренция в РФ-сегменте.

### Куда какой формат (Трек A)

| Площадка | Что заходит | Что запрещено/бесполезно | Стоимость |
|---|---|---|---|
| **Хабр** | Только технический угол: архитектура фолбэка laozhang↔apimart, идемпотентный копеечный ledger, OpenAI-совместимый эндпоинт, Sandbox API на E2B | Рекламные публикации — только в блоге компании либо однократно в «Я пиарюсь»; продуктовый пост вне блога = минусы и бан | Личные статьи бесплатно; блог компании платный — сейчас не по бюджету |
| **vc.ru** | Подборки, сравнения, личный опыт, разборы экономики | Коммерческий аккаунт скрыт из ленты и не индексируется — только личный | Бесплатно |
| **DTF** | Гайды и подборки (пересечение по AI-генерации картинок/видео) | Прямая продажа | Бесплатно |
| **sostav.ru/blogs** | Самопубликация, сильный домен | — | Бесплатно |
| **Дзен** | Массовая B2C-аудитория, алгоритм даёт охват новым каналам, но нужна регулярность | Разовая публикация = ноль эффекта | Бесплатно; ПромоСтраницы — платный CPC, конкурирует с бюджетом Директа |

Ориентир: конкурент BotHub ведёт блог на Хабре 2–3 статьи/нед, 5–17 тыс.
просмотров на материал — почти все статьи не про себя, а про LLM, сравнения,
prompt injection. Копировать механику, не бюджет.

### Что требует кода в контент-части

- `create_seo_posts` — одна захардкоженная статья, не генератор. Настоящий
  генератор — `generate_seo_articles.py`, но `BRIEFS`/`LOCALE_META` покрывают
  только en/fa/tr/id/ar — **русских брифов нет**, их нужно дописать (черновики
  создаются с `is_published=False` — ручная вычитка обязательна в любом случае).
- В `Post` есть `faq_items` (FAQPage) и M2M `neural_networks` — использовать оба:
  FAQ даёт расширенный сниппет, M2M — перелинковку статья↔карточки моделей.
  Перелинковка сейчас главный недоиспользованный SEO-ресурс.
- `/g/[slug]` отсутствуют в sitemap — добавить выборочно (30–50 лучших
  генераций с промптами, не все подряд).

## 4. Малый бюджет (ориентир 10–20 тыс. ₽ суммарно)

| Действие | Бюджет | Усилие | Отдача | Риск |
|---|---|---|---|---|
| Сидинг в мелкие/средние TG-каналы | 5–15 тыс. ₽ или бартер промокодами | Среднее | Средняя-высокая | Средний |
| Plati.market / Digiseller | ~0 ₽ + комиссия | Среднее (нужен код) | Низкая (канал обнаружения, не выручки) | Средний |
| Платное включение в существующие подборки | По запросу к редакциям | Низкое | Средняя | Низкий |

### 4.1. Telegram-сидинг

**Отбор каналов** через бесплатный каталог TGStat (поиск/статистика бесплатны,
премиум-аналитика ~3360 ₽/мес не нужна на старте) и Telemetr:
- 3–30 тыс. подписчиков (крупнее не окупится при чеке 149 ₽);
- тематики: нейросети, ИИ-инструменты, заработок в интернете, фриланс,
  дизайн/контент;
- ER > 15%, без метки накрутки в TGStat;
- в Telemetr смотреть историю рекламных постов — если канал крутит казино/крипту,
  пропускать.

**Оплата.** CPM в массовых нишах — до ~400 ₽; канал на 5 тыс. с охватом
1,5–2 тыс. — ориентировочно 300–800 ₽/пост. Первые 5–7 размещений — не деньгами,
а связкой:
1. **Промокод на баланс до 150 ₽ для подписчиков** — адресный потолок по
   k≤1.55 (см. TARIFFS.md §5). `PromoCode` + `UsedPromoCode.unique_together`
   безопасно ограничивает одно погашение на аккаунт.
2. **Персональная реферальная ссылка блогера** `?ref=CODE` — 15/40/90/130/200 ₽
   за оплатившего по тарифу.

**Два капкана:**

⚠️ Реферальный бонус начисляется **только при оплате через Робокассу**. Если
блогер ведёт людей в бот и они платят Stars — блогер увидит ноль. Решение: либо
креатив ведёт на **сайт** (`aineron.ru/?ref=CODE`, cookie 30 дней), либо блогеру
ставится **нативная партнёрка Telegram** (покрывает Stars). Не смешивать —
объяснить блогеру, какая рельса какие платежи считает.

⚠️ **Промокод нельзя активировать в боте** (обработчика нет). Если креатив ведёт
в бота, а активация только на сайте — часть выданной скидки теряется в разрыве
сценария. До правки кода (§7) — все промо-креативы ведут строго на сайт.

**Бюджет теста:** 5 каналов × ~1000 ₽ = 5000 ₽ за первую волну. Метрика успеха —
не клики, а регистрации ≤80 ₽ и оплаты ≤300 ₽. Канал с CPA оплаты ниже 300 ₽ —
докупаем повторно и повышаем ставку.

### 4.2. Plati.market / Digiseller — честно: канал маленький

Не Яндекс.Маркет — туда SaaS-подписку физически нельзя завести как товар с
доставкой. Plati/Digiseller — маркетплейс цифровых товаров (ключи, коды,
подписки), подходит по формату.

Экономика: комиссия площадки ~7% (заявлено «от 3%» + платные функции) + движок
Digiseller — суммарно ориентировочно ~10%. При возврате с отрицательным отзывом
удерживаются комиссии WebMoney/площадки/Digiseller — возврат стоит дороже сделки.

При потолке номинала 30–50 ₽ массово: товар за 50 ₽ минус ~10% комиссии = **45 ₽
выручки со сделки — это не канал выручки**, а канал обнаружения (люди ищут
«ChatGPT подписка» рядом со Steam-ключами, часть попадёт на сайт как обычные
пользователи).

**Как делать:**
- Товар «Промокод на 50 ₽ баланса aineron.ru», цена ~49–59 ₽, 1–2 SKU.
- Автоотгрузка: заранее созданный пул кодов, загруженный в Digiseller.
- В описании обязательно: «код активируется на сайте aineron.ru в разделе
  баланса» (в боте не активируется).
- Второй бесплатный крючок в карточке — упоминание бесплатного тарифа/моделей.

**Про риск абьюза — важная поправка.** `ShadowBanMiddleware` сам не банит, лишь
реагирует на уже стоящий флаг, а флаг ставится только в legacy-регистрации, не
в текущем DRF-пути. То есть:
1. Ложные баны покупателей за одним NAT/прокси — риск в основном дормантный,
   современный фронт их не трогает.
2. Обратная сторона: защиты от мультиаккаунтов под промокоды сейчас нет.
   Единственная реальная защита — `UsedPromoCode.unique_together` (1 код на
   аккаунт).
3. Поэтому: `usage_limit=1` на каждый Plati-код, номинал не выше 50 ₽, раз в
   неделю смотреть долю аккаунтов, погасивших код без единой платной генерации.

### 4.3. Платное попадание в существующие подборки

## 6. Реферальная программа как growth loop

Она безубыточна и уже учтена в k (см. TARIFFS.md §6) — узкое место не цена,
а активация: люди просто не знают, что она есть.

**Триггерные механики размещения (не «баннер в кабинете»):**
1. После первой успешной генерации — самый заряженный момент: «Понравилось?
   Позовите друга — получите до 200 ₽ на баланс».
2. После пополнения — экран успешной оплаты сейчас пустой с точки зрения growth.
3. В `/start` и главном меню бота (deeplink `t.me/{BOT}?start=ref_{code}` уже
   работает) — пользователь должен узнать про `/referral`.
4. Уведомление о заработке: «Ваш друг оплатил тариф Про — вам начислено 90 ₽» —
   лучший триггер на второе приглашение.
5. Шеринг генераций (`/g/[slug]`, кнопка «повторить промпт») — добавить `?ref=`
   автора генерации, каждая расшаренная картинка становится реферальной ссылкой.
   Самая дешёвая виральность из доступных.

**Что стоит починить в самой программе:**
- Бонус не начисляется при оплате Stars/криптой/автопродлением — первое
  критично для бот-аудитории, третье тихо убивает мотивацию на дистанции.
- Вывод на карту гейтится `can_convert_to_rub` (по умолчанию False), а рублёвая
  ветка `Tariff.referral_bonus` в `setup_tariffs` не заполняется — фактически
  все получают бонус на баланс. Коммуницировать именно так («до 200 ₽ на
  баланс»), без обещаний вывода.

**Механика-усилитель без кода:** двусторонний оффер в креативах — приглашённому
промокод 50 ₽, пригласившему 15–200 ₽ по тарифу. Обе части укладываются в
k≤1.55.

## 8. Чего НЕ делать на этой стадии

| Не делать | Почему именно сейчас |
|---|---|
| Telegram Ads (официальный кабинет) | Минимум 250 € + ~20% комиссия реселлера + 22% НДС — при чеке 149 ₽ бюджет кончится раньше данных |
| CPA-сети / арбитраж | Минималки и вознаграждение не сходятся с ARPU 149–899 ₽ при k≤1.55; мотивированный трафик приносит тех, кто берёт грант 10 ₽ и уходит |
| Массовая генерация 122+ статей DeepSeek'ом | Свежий домен + пачка сгенерированного контента = риск фильтра на весь сайт |
| Платный блог компании на Хабре сейчас | Дорого для текущего бюджета; личные технические статьи дают ~80% эффекта бесплатно |
| Product Hunt / зарубежные площадки | Не та география; УТП «без VPN, за рубли» для зарубежной аудитории бессмысленно — это канал для aineron.net с другим позиционированием |
| Яндекс.Маркет / Ozon / WB | SaaS-подписку туда физически не завести как товар |
| Крупные блогеры / YouTube-интеграции | 100–500 тыс. ₽ за интеграцию против чека 149 ₽ — даже 1000 регистраций не окупят |
| Instagram / VK-таргет / SMM «для присутствия» | Аудитория ниши в Telegram и на vc/Хабре; VK-таргет для AI-сервисов даёт дорогой нецелевой клик |
| Мобильное приложение | Уже есть PWA и Mini App; сторы — месяцы модерации ради нулевого прироста |
| Агентство/SEO-подрядчик на аутсорсе | 50–150 тыс. ₽/мес — при таком бюджете оплатите чужое обучение на своей нише |
| Промокоды выше 150 ₽ | Потолок k≤1.55 — 150 ₽ только адресно блогерам, не в открытый доступ |
| Скидки >50% на тарифы | Валидатор `discount_percent` уже режет на 50 — глубже маржа не выдержит |

## 9. Как понять через 30 дней, что сработало

Смотреть не на трафик, а на два уже определённых порога: регистрация ≤80 ₽,
оплата ≤300 ₽.

| Метрика | Ориентир к концу месяца 1 |
|---|---|
| Внешних ссылающихся доменов | 6–10 (каталоги + площадки) |
| Страниц в индексе Яндекса | 100+ из ~168 в sitemap |
| Небрендовых визитов из поиска | Первые десятки (норма — Трек B ещё не созрел) |
| Визитов с vc/DTF/sostav | 300–1500 суммарно на статью |
| Регистраций из бесплатных каналов | 50–150 |
| CPA оплаты по TG-сидингу | ≤300 ₽, иначе канал закрывается |

Правило распределения усилий на месяц 2: удваивать только каналы с CPA оплаты
≤300 ₽, остальное замораживать, не «докручивать».
