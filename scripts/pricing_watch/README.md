# Еженедельная сверка цен с RouterAI

Локальный скрипт (не требует Docker/SSH/доступа к нашей БД) для регулярной
проверки: не отстали ли наши цены от конкурента больше чем на разумный
процент. Не автоматизирует Gen-API (второго конкурента) — см. «Ограничения»
ниже.

## Установка (один раз)

```bash
pip install requests beautifulsoup4
```

## Запуск

```bash
python compare_prices.py
```

Полезные флаги:

```bash
python compare_prices.py --threshold 10        # показывать отклонения больше 10% (по умолчанию 15)
python compare_prices.py --out report.csv       # сохранить полный отчёт по всем 68 моделям в CSV
python compare_prices.py --delay 0.5            # пауза между запросами к routerai.ru (вежливость к их серверу)
```

Скрипт **ничего не меняет** в базе данных — только выводит отчёт. Что делать
с найденными отклонениями (какие цены на самом деле поднять/опустить) —
решать отдельно, глядя на отчёт.

## Что делает

1. Тянет наши текущие цены с публичного `aineron.ru/api/v1/catalog/networks/`.
2. Тянет цены с routerai.ru по 49 из 68 моделей (остальные 19 конкурент не
   продаёт вообще — см. `routerai_mapping.json`, поле `router_url: null`).
3. Приводит к сопоставимым единицам: текст — через профиль токенов
   (6000 вход / 1500 выход, как в `PRICING_SIMPLIFICATION_PLAN.md` §3),
   картинки — ₽/фото напрямую, видео — ₽/сек × наша реальная длительность.
4. Показывает отклонение и цену «конкурент × 0.95» как ориентир.

## Ограничения (честно, чтобы не удивляться)

- **Gen-API не сверяется автоматически** — у него нет стабильного URL на
  модель (общий текстовый дамп прайс-листа, ломкий для парсинга). RouterAI
  дешевле Gen-API в ~93% случаев (39 из 42 при сверке 07.09.2026), так что
  еженедельно этого достаточно. Раз в 1-2 месяца стоит попросить Claude Code
  заново снять `genapi.txt` и пересчитать — на 4 моделях Gen-API оказывался
  дешевле (DeepSeek V4 Pro, GPT-Image-1, GPT-Image-2, Seedance 2.0).
- **6 моделей изображений биллятся конкурентом в ₽/1М токенов, а не ₽/фото**
  (Nano Banana/Gemini-семейство, GPT-Image-семейство) — конвертация в ₽/фото
  требует реальное число токенов на фото по докам OpenAI/Google (см.
  `align_image_pricing_to_competitors.py`), скрипт такие модели помечает
  «сверить руками», а не гадает.
- **19 моделей вообще не продаются у RouterAI** — Vidu, Flux Kontext,
  Midjourney, Wan 2.7 Image, Z-Image Turbo и т.д. Для них ориентир по
  прежнему только Gen-API (ручная сверка) или наш реальный опт × 1.05
  (пол по марже, см. `apply_image_price_margin_floor.py`).
- Если routerai.ru поменяет вёрстку страницы — парсер сломается тихо (вернёт
  «не нашёл» для всех моделей разом). В этом случае просто попросите
  Claude Code починить селекторы в `parse_routerai_page()`.

## Файлы

- `compare_prices.py` — сам скрипт.
- `routerai_mapping.json` — карта: наш slug → URL модели на routerai.ru
  (+ для видео: наша реальная длительность в секундах, для текста: профиль
  токенов). Собрана вручную 07.09.2026 при полном аудите 68 моделей — при
  добавлении новых моделей в каталог нужно дописывать сюда вручную.
